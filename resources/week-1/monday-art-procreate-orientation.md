## Quick Reference

### Canvas Setup
1. Tap **+** icon in gallery (top right)
2. Choose **Custom Size** or use preset
3. For game art: **2048x2048** at **300 DPI** is a good start

### Essential Gestures
- **Two-finger tap** - Undo
- **Three-finger tap** - Redo
- **Two-finger pinch** - Zoom in/out
- **Two-finger rotate** - Rotate canvas
- **Hold with one finger** - Draw straight line

### Finding Brushes
1. Tap **Brush** icon (top right)
2. Browse categories: Sketching, Inking, Painting, Artistic
3. **Good starter brushes:**
   - Sketching > 6B Pencil (drawing)
   - Inking > Studio Pen (clean lines)
   - Painting > Round Brush (filling)
   - Artistic > Nikko Rull (painterly feel)

### Color Picker
- Tap **Color** circle (top right)
- Use **Disc** for hue/saturation
- Use **Classic** for familiar palette
- **Hold finger on canvas** to sample existing color
