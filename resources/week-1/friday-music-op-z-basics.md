## Quick Reference

### OP-Z Track Layout
| Tracks 1-4 | Tracks 5-8 | Tracks 9-16 |
|------------|------------|-------------|
| Drums | Synths | Control/FX |
| Kick, Snare, Hats, Perc | Bass, Lead, Arp, Chord | Tape, FX, etc. |

### Basic Navigation
- **Track buttons** (bottom row): Select which track to edit
- **Step keys** (top row): Add/remove notes on steps
- **Tempo button** (hold): Access tempo and metronome
- **Project button** (hold): Navigate projects and patterns

### Creating a Simple 8-Bar Loop

1. **Select a Track**
   - Press track button (1-8) to choose instrument

2. **Choose a Sound**
   - Hold track button + turn encoder to browse sounds
   - For menu music: Try track 5-8 (synths) for pads/chords

3. **Add Notes**
   - Press step keys to add notes on those steps
   - Lit = note plays, unlit = silence

4. **Adjust Note Properties**
   - Hold a step + turn encoders to change:
     - Pitch, length, velocity, etc.

5. **Build Up**
   - Add a gentle bass (track 5)
   - Add a pad/chord progression (track 8)
   - Maybe light percussion (track 1-4) — or skip for ambient

6. **Set Length to 8 Bars**
   - Hold **Track** + press step 8 to set pattern length

### Menu Music Tips
- **Slow tempo**: 70-90 BPM works well
- **Simple chords**: Major or suspended chords feel welcoming
- **Light texture**: Pads, soft synths, maybe gentle bells
- **Space**: Leave gaps — menu music shouldn't demand attention
- **Loop seamlessly**: Make sure end connects to beginning

### Exporting Audio
1. Connect OP-Z to computer via USB
2. OP-Z appears as a drive
3. Navigate to audio output folder
4. Recorded audio appears as .wav files
5. Rename and organize in your project folder
