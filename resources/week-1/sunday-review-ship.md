## Quick Reference

### Exporting a POC Build (Optional)

**From Godot:**
1. Project → Export
2. Add export preset (Windows/Mac/Linux)
3. Download export templates if prompted
4. Set export path
5. Click "Export Project"

**Note:** For Week 1, a video capture is perfectly fine. Don't spend time on export templates yet.

### Capturing Video (Recommended)

**Mac - QuickTime:**
1. File → New Screen Recording
2. Select your game window
3. Record 15-30 seconds of gameplay
4. File → Save

**OBS Studio:**
1. Add Window Capture
2. Start Recording
3. Play your game
4. Stop Recording

### Definition of "Shipped" for Week 1
Your POC is shipped if:
- [ ] It runs without crashing
- [ ] There's some 3D shape that isn't the default cube
- [ ] Something shoots something
- [ ] Music plays
- [ ] You have a video or playable file to show

**It does NOT need to:**
- Look good
- Be fun
- Have proper game logic
- Be polished in any way
