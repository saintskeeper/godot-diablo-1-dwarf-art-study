# Week 2 Resources

> **Theme:** Study the masters, then make it yours
> **Study:** Pick a classic game scene (Diablo 1, Chrono Trigger, FF6, etc.)
> **POC:** Your own scene inspired by the original — same mood, your style

---

## This Week's Focus

Week 2 is about learning through deconstruction and reinterpretation. You'll:

1. **Study** a classic game scene obsessively — understand WHY it works
2. **Extract principles** — not just what they did, but the transferable lessons
3. **Build your own version** in Godot — same mood, YOUR voice
4. **Add your style** — push beyond the reference, make it exciting to YOU

By Sunday, you should have a complete scene in Godot that evokes the same feeling as your reference, but looks and sounds like something only you could have made.

## The Process

```
┌─────────────────────────────────────────────────────────────┐
│ MONDAY: STUDY                                               │
│ Choose scene → Screenshot → Analyze deeply → Extract        │
│ principles → Sketch your interpretation                     │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ TUESDAY: FOUNDATION                                         │
│ Block composition → Place major shapes → Set up layers      │
│ Match VALUES before anything else                           │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ WEDNESDAY: MOOD                                             │
│ Add CanvasModulate → Place lights → Dial in colors          │
│ Goal: FEEL the vibe, even if colors differ                  │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ THURSDAY: LIFE                                              │
│ Add particles → Animate elements → Add YOUR touches         │
│ This is where your style emerges                            │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ FRIDAY: AUDIO                                               │
│ Base ambience → Point sources → Random events               │
│ Audio for YOUR version, not the original                    │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ SATURDAY: POLISH                                            │
│ Final pass → Record video → Compare to reference            │
│ Same energy, different execution                            │
└─────────────────────────────────────────────────────────────┘
```

## Key Godot Concepts This Week

| Concept | What It Does |
|---------|--------------|
| `CanvasLayer` | Separates rendering into layers (background/foreground) |
| `CanvasModulate` | Tints entire canvas — use for ambient darkness |
| `PointLight2D` | Radiates light from a point — torches, lamps |
| `GPUParticles2D` | Efficient particle effects — dust, fire, magic |
| `AudioStreamPlayer` | Non-positional audio — ambience, music |
| `AudioStreamPlayer2D` | Positional audio — sounds at specific locations |
