# 2026 Solo Game Dev Curriculum — Constraints

> **Start Date:** December 7, 2025  
> **End Goal:** Steam-published indie game by December 25, 2026  
> **Profile:** 32yo business owner, 3-month-old at home, 10+ years software dev

---

## Time Budget

| Block | Window | Context | Best For |
|-------|--------|---------|----------|
| Morning | 5–8 AM | With baby, split attention | Passive learning, OP-Z noodling, Procreate sketching |
| Evening | 5–8 PM | Focus time available | Blender, Godot, deliberate practice |

- **Daily commitment:** 15–30 min focused activity
- **Weekly total:** ~2–3.5 hours hands-on creative work
- **Weekends:** Same rhythm (no bonus time assumed)

```
Blender (3D) → Render to 2D → Painted/Stylized Aesthetic → Godot
```

---

## Aesthetic North Stars

- **Kingdom Rush** — clean silhouettes, readable at small scale, painterly
- **Warcraft 3** — chunky, stylized, exaggerated proportions
- **Balatro** — tight feedback loops, visual clarity, personality in simplicity

**Guiding Principle:** Simple > Detailed. Readable > Realistic. Ship > Perfect.

---

## Genre Focus

**Primary:** Tower Defense or Card Game (or hybrid)  
**Design DNA:**
- Quick sessions
- High replayability
- Strategic depth with accessible entry
- Monetization-friendly structure

**References:** Balatro, Hearthstone, Kingdom Rush, Slay the Spire

---

## Goal Structure

### Weekly
- **1 Proof of Concept scene** that integrates:
  - At least one new/refined 3D→2D asset
  - At least one sound/music element
  - Functional in Godot (even if minimal)

### Quarterly Milestones (to be refined)
- **Q1 2026:** Foundation — core skills in Blender/Procreate, Godot prototype loop established
- **Q2 2026:** Vertical slice — one complete playable loop with placeholder-to-decent art
- **Q3 2026:** Content & polish — expand content, refine aesthetic, playtest
- **Q4 2026:** Ship prep — Steam page, trailer, launch

### Annual
- **December 25, 2026:** Game live on Steam

## The Agentic Augmentation Plan

As each skill is mastered:
1. Document the workflow explicitly
2. Create clear prompts/pipelines for AI agents
3. Build tooling to offload repetitive tasks
4. Reserve human creativity for design decisions and polish

**Order of automation:**
1. Blender workflows (model generation, render settings)
2. Godot boilerplate (scene setup, common patterns)
3. Asset pipeline (batch processing, naming conventions)

## Hard Rules

1. **No perfectionism** — ship the ugly version
2. **Scope down, not up** — every feature is a maybe until it's done
3. **15 minutes counts** — momentum > duration
4. **One scene per week** — non-negotiable forcing function
5. **Sleep > grind** — you have a baby, sustainability wins
