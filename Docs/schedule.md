# 2026 Solo Game Dev Curriculum — Weekly Schedule

> **Rhythm:** 7 days/week, 15–30 min daily  
> **Weekly Output:** 1 POC scene (asset + audio + functional in Godot)

---

## Time Block Reference

| Block | Window | Energy | Use For |
|-------|--------|--------|---------|
| 🌅 Morning | 5–8 AM | Fragmented (baby) | Low-friction creative: sketching, OP-Z, tutorials, reference gathering |
| 🌙 Evening | 5–8 PM | Focused | Deep work: Blender, Godot, deliberate practice |

---

## Weekly Template

| Day | Domain | Block | Focus |
|-----|--------|-------|-------|
| **Monday** | 🎨 Art | 🌅 + 🌙 | Procreate fundamentals / reference study |
| **Tuesday** | 🧊 3D | 🌙 | Blender modeling session |
| **Wednesday** | 🎮 Engine | 🌙 | Godot — implement/iterate on mechanic |
| **Thursday** | 🧊 3D | 🌙 | Blender → render pipeline (3D to 2D) |
| **Friday** | 🎵 Music | 🌅 + 🌙 | OP-Z — compose/refine track or SFX |
| **Saturday** | 🎮 Integration | 🌙 | Assemble week's assets into POC scene |
| **Sunday** | 📋 Review | 🌅 | Ship POC, document, plan next week |

---

## Daily Micro-Structure (15–30 min)

```
[0–2 min]   Intention: What's the ONE thing I'm doing?
[3–25 min]  Execute: Do the thing. No switching.
[26–30 min] Capture: Screenshot, export, or note what happened.
```

**Rule:** If you only have 15 min, skip the capture. Momentum > documentation.

---

## Domain Breakdown

### 🎨 Monday — Art (Procreate)
**Morning options:**
- Gesture sketches (5–10 quick poses)
- Study a reference image from aesthetic north stars
- Watch a short tutorial (Procreate techniques, stylization)

**Evening options:**
- Deliberate practice on weekly skill focus
- Paint a concept for this week's POC asset
- Color/value studies from Kingdom Rush or WC3 screenshots

---

### 🧊 Tuesday — Blender (Modeling)
**Evening focus:**
- Follow curriculum exercise (see `curriculum-q1.md`)
- Block out this week's POC asset
- Practice modifiers, topology, or sculpting basics

**Beginner phase (first 8 weeks):** Tutorial-driven, learn the tool  
**Builder phase (week 9+):** Project-driven, make game assets

---

### 🎮 Wednesday — Godot (Mechanics)
**Evening focus:**
- Prototype one mechanic or system
- Refactor/clean up last week's code
- Experiment with shader or VFX for aesthetic

**You're strong here** — use this day to stay sharp and integrate learnings from other domains.

---

### 🧊 Thursday — Blender (Render Pipeline)
**Evening focus:**
- Take Tuesday's model → set up lighting/materials
- Render to 2D sprite (orthographic or stylized)
- Batch render if multiple angles needed
- Post-process in Procreate if needed

**Goal:** Establish repeatable 3D→2D pipeline you can later automate.

---

### 🎵 Friday — Music (OP-Z)
**Morning options:**
- Noodle and capture ideas (record everything)
- Study a reference track's structure

**Evening options:**
- Compose 8–16 bar loop for POC
- Design 2–3 SFX (UI clicks, hit sounds, etc.)
- Mix/master previous session's work

**You're intermediate here** — focus on speed and game-appropriate sounds.

---

### 🎮 Saturday — Integration Day
**Evening focus (longer session if possible):**
- Import week's assets into Godot
- Wire up audio
- Make it *playable* (even if ugly)
- Record a 15-second clip for dev log

**This is the forcing function.** Nothing is done until it's in-engine.

---

### 📋 Sunday — Review & Ship
**Morning (with coffee, baby permitting):**
- Export/publish POC (even if to a private folder)
- Write 3–5 sentences for dev log
- Identify: What worked? What sucked? What's next week's focus?
- Set Monday's specific intention

**End state:** POC shipped, next week planned, inbox zero on creative debt.

---

## Flexible Slots

Life with a 3-month-old is chaos. If a day falls apart:

| If you miss... | Recover by... |
|----------------|---------------|
| Monday (Art) | Quick sketch during any morning this week |
| Tuesday (Blender) | Combine with Thursday's session |
| Wednesday (Godot) | Push to Saturday integration |
| Thursday (Render) | Render during Saturday integration |
| Friday (Music) | Use placeholder audio, catch up next week |
| Saturday (Integration) | Sunday becomes integration + review |
| Sunday (Review) | 5-min voice memo instead of written review |

**One bad day ≠ failed week.** Protect Saturday integration above all else.

## Phase Adjustments

This schedule shifts as you level up:

| Phase | Weeks | Schedule Emphasis |
|-------|-------|-------------------|
| **Foundation** | 1–12 | Heavy on tutorials, learning tools, ugly POCs are fine |
| **Builder** | 13–30 | Shift to project-driven, assets feed into real game |
| **Production** | 31–45 | Schedule serves the game, not skill-building |
| **Ship** | 46–52 | Polish, marketing, Steam prep — creative time shrinks |
