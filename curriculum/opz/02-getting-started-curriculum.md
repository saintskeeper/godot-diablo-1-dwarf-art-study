# OP-Z Getting Started: Week 1 Curriculum

**Goal**: Master the fundamental operations of the OP-Z - projects, patterns, tracks, playback, and basic sound selection.

**Time Commitment**: 15-30 minutes per day, 5 days

---

## Day 1: Projects & Patterns (20 minutes)

### Understanding the OP-Z Structure

The OP-Z organizes music in this hierarchy:
- **Project** = Your entire song (10 available, numbered 1-0)
- **Pattern** = Up to 16 variations per project
- **Track** = 16 tracks per pattern (drums, synths, FX, control)

```
PROJECTS (1-0 on value keys)
    └── PATTERNS (1-16 on step buttons)
            └── TRACKS (1-16)
                    ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐
                    │KCK│ │SNR│ │PRC│ │SMP│ │BAS│ │LED│ │ARP│ │CHD│
                    └───┘ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘
                    ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐
                    │FX1│ │FX2│ │TAP│ │MST│ │PRF│ │MOD│ │LGT│ │MOT│
                    └───┘ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘
```

### Exercise 1: Explore Factory Projects (10 min)

**Task**: Listen to the 9 preloaded factory projects to understand what's possible.

1. Hold [P] + press Value Key (1) - load Project 1
2. Press (Play) to start playback
3. While playing, hold [P] + press Value Key (2) to switch projects immediately
4. Repeat for projects 1-9
5. Press (Stop) when done

**Observe**: Notice how the white value key illuminates when holding [P] to show current project.

### Exercise 2: Navigate Patterns (10 min)

**Task**: Learn to switch between patterns within a project.

1. Load Project 1: Hold [P] + Value Key (1)
2. Press (Play)
3. Hold [P] + Step (1) - observe pattern switches instantly
4. Hold [P] + Step (2), Step (3), Step (4) - explore different patterns
5. Watch the step LEDs while holding [P]:
   - **White lit** = Pattern available, currently chained
   - **White flash** = Current pattern
   - **Red lit** = Pattern available but not chained
   - **Unlit** = No pattern

**Challenge**: While playing, switch between 4 different patterns in Project 1.

### Today's Takeaway
You now understand that Project 0 is blank (your workspace), projects 1-9 have factory content, and patterns let you create variations within a song.

## Day 2: Tracks & Sound Selection (25 minutes)

### Understanding Tracks

Each pattern has 16 tracks organized in groups:
- **Drums** (1-4): Kick, Snare, Perc, Sample
- **Synths** (5-8): Bass, Lead, Arp, Chord
- **Control** (9-16): FX1, FX2, Tape, Master, Performance, Module, Light, Motion

### Exercise 1: Select and Hear Tracks (10 min)

**Task**: Learn to isolate and listen to individual tracks.

1. Load Project 1: Hold [P] + Value Key (1)
2. Press (Play)
3. Hold (Track) + Step (1) [Kick] - select kick drum track
4. Release and listen - you've isolated the kick track
5. Repeat for each track:
   - Hold (Track) + Step (2) [Snare]
   - Hold (Track) + Step (3) [Perc]
   - Hold (Track) + Step (5) [Bass]
   - Hold (Track) + Step (6) [Lead]

**Observe**: The selected step button illuminates white when holding (Track).

### Exercise 2: Explore Plugs & Presets (15 min)

**Task**: Understand the three-level sound selection system.

```
SOUND SELECTION HIERARCHY:

(Track) + Step (1-8)     →  Select Track
    ↓
(Track) + Value Key (1-0) →  Select Plug (sound engine/kit)
    ↓
(Track) + White Key (F-E) →  Select Preset (variation)
```

**Drill - Drum Track**:
1. Hold (Track) + Step (1) [Kick] - select kick track
2. Keep holding (Track), press Value Key (1) - select plug slot 1
3. Keep holding (Track), press Value Key (2) - different kick kit
4. Release (Track)
5. Hold (Track) again, press white Component Key (F) - preset 1
6. Hold (Track), press white Component Key (G) - preset 2
7. Play different white keys to hear different kick presets

**Drill - Synth Track**:
1. Hold (Track) + Step (5) [Bass] - select bass track
2. Hold (Track) + Value Key (1) - select bass engine 1
3. Hold (Track) + Value Key (3) - try different bass engine
4. Hold (Track) + white Component Key (F) - bass preset 1
5. Hold (Track) + white Component Key (A) - bass preset 2

**Visual Feedback**:
- Value keys illuminate **white** where plugs exist
- Value keys **flash white** for current plug
- Component keys illuminate **white** where presets exist
- Component keys **flash white** for current preset

### Today's Takeaway
Tracks organize your music. Plugs are sound engines. Presets are variations. Always select Track → Plug → Preset.

## Day 3: Playing & Recording Notes (30 minutes)

### The Keyboard

The OP-Z keyboard has 24 keys spanning 2 octaves:
- **Value Keys** (black) = sharps/flats
- **Component Keys** (white) = natural notes
- Range: F1 to E2 (default, adjustable with +/- octave)

### Exercise 1: Play Drum Hits (10 min)

**Task**: Learn how drum tracks map individual hits to keyboard keys.

1. Load Project 0 (blank): Hold [P] + Value Key (0)
2. Select kick track: Hold (Track) + Step (1)
3. Hold (Track) + Value Key (1) - load a kick drum kit
4. Release (Track)
5. Press different keyboard keys - each key triggers a different drum hit
6. Find your favorite kick sound and remember which key it is

**Repeat for other drum tracks**:
- Snare: Hold (Track) + Step (2), then play keyboard
- Perc: Hold (Track) + Step (3), then play keyboard

**Important**: The last key you press is remembered for sequencing!

### Exercise 2: Play Synth Notes (10 min)

**Task**: Understand synth keyboard mapping and polyphony.

1. Select bass track: Hold (Track) + Step (5)
2. Hold (Track) + Value Key (1) - load bass preset
3. Release (Track)
4. Play keyboard - notes are melodic (F, G, A, B, C, D, E, F...)
5. Try playing multiple notes - bass is **monophonic** (1 note at a time)

6. Select chord track: Hold (Track) + Step (8)
7. Play multiple keys together - chord is **4-note polyphonic**

**Default Polyphony**:
- Drums: 2 notes
- Bass: 1 note (mono)
- Lead: 3 notes
- Arp: 1 note (arpeggiated)
- Chord: 4 notes

### Exercise 3: Octave Shifting & Pitch Bend (10 min)

**Octave Shifting**:
1. Select lead track: Hold (Track) + Step (6)
2. Play some notes on keyboard
3. Press (+) once - value keys flash to show octave up
4. Play keyboard - notes are higher
5. Press (-) twice - go down two octaves
6. Press (+) once - return to middle

**Pitch Bend**:
1. Press and hold any keyboard key
2. While holding, press the left side of [Bend] - pitch bends down
3. Try right side of [Bend] - pitch bends up
4. Watch step LEDs show bend amount as a bar graph

### Today's Takeaway
The keyboard plays different drum hits or melodic notes depending on track type. Last note played = note that gets sequenced.

## Day 4: Tempo, Metronome & Transport (20 minutes)

### Transport Controls

```
┌────┐
│ ▶  │  (Play) = Start/Restart playback
└────┘

┌────┐
│ ■  │  (Stop) = Stop playback
└────┘  Press again when stopped = Panic (kill all notes)
        Press 3rd time = Super panic (clear audio buffers)
```

### Exercise 1: Playback Control (5 min)

1. Load Project 1: Hold [P] + Value Key (1)
2. Press (Play) - starts from beginning
3. Let it play for 4 bars
4. Press (Play) again while playing - restarts from beginning
5. Press (Stop) - stops and returns to start

**LED Indicators During Playback**:
- **Step buttons**: Red = step has notes, White = currently playing step
- **Keyboard keys**: Flash white when notes trigger

### Exercise 2: Set Tempo (10 min)

**Check Current Tempo**:
1. Hold [Tempo]
2. Value keys flash in sequence showing BPM (e.g., 1-2-5 = 125 BPM)

**Set Precise Tempo** (120 BPM):
1. Hold [Tempo]
2. Press Value Keys: (1), (2), (0) in sequence
3. Release [Tempo]

**Adjust Tempo with Dial**:
1. Hold [Tempo] + turn {Green} dial clockwise - tempo increases
2. Hold [Tempo] + turn {Green} dial counter-clockwise - tempo decreases
3. Watch value keys display BPM as you adjust (range: 40-200)

**Tap Tempo**:
1. Hold [Tempo]
2. Tap any white Component Key 4+ times at your desired tempo
3. OP-Z calculates BPM from your taps

**Nudge Tempo** (temporary adjustment):
1. Press (Play) to start playback
2. Hold [Tempo] + tap (+) three times - tempo nudges up slightly
3. Hold [Tempo] + tap (-) three times - tempo nudges down slightly

### Exercise 3: Metronome (5 min)

**Adjust Metronome Volume**:
1. Hold [Tempo] + turn {Red} dial clockwise - louder click
2. Hold [Tempo] + turn {Red} dial counter-clockwise - quieter
3. Turn fully counter-clockwise - metronome off

**Change Metronome Sound**:
1. Hold [Tempo] + turn {Yellow} dial
2. Options cycle through: Clave, Swedish, English, German, Japanese, Italian

**Try**: Set metronome to English count ("One, Two, Three, Four")

### Exercise 4: Swing (Practice with Feel)

**Adjust Swing**:
1. Load a project with drums: Hold [P] + Value Key (1)
2. Press (Play)
3. Hold [Tempo] + turn {Blue} dial to center (neutral = green LED)
4. Hold [Tempo] + turn {Blue} dial right - adds swing
5. Hold [Tempo] + turn {Blue} dial left - reduces swing
6. Adjust by ear until it feels good

### Today's Takeaway
Tempo range is 40-200 BPM. Metronome helps you stay in time. Swing adds human feel to rigid sequences.

## Day 5: Project Management & Review (25 minutes)

### Exercise 1: Create Your First Blank Project (10 min)

**Task**: Set up a fresh workspace in Project 0.

1. Load Project 0: Hold [P] + Value Key (0)
2. Verify it's blank - press (Play), should be silent
3. Set tempo to 120: Hold [Tempo] + press (1), (2), (0)
4. Set metronome to comfortable volume: Hold [Tempo] + turn {Red} dial
5. Enable metronome English count: Hold [Tempo] + turn {Yellow} dial

**Projects Auto-Save**: Your work is automatically saved! Manual save can be enabled with Hold [P] + (Track) for several seconds.

### Exercise 2: Copy a Project (5 min)

**Task**: Copy Project 1 to Project 0 to preserve factory content.

1. Hold [P] + Value Key (1) - select source (Project 1)
2. Continue holding [P] + Value Key (0) for several seconds
3. Step buttons illuminate white left-to-right - wait for completion
4. Release - Project 1 is now copied to Project 0
5. Hold [P] + Value Key (0) to confirm it now has content

### Exercise 3: Clear a Pattern from a Track (5 min)

**Task**: Remove kick drum from a pattern.

1. Load Project 1: Hold [P] + Value Key (1)
2. Press (Play) - listen to full pattern
3. Select kick: Hold (Track) + Step (1) [Kick]
4. Keep holding (Track) + hold (Stop) for several seconds
5. Step LEDs illuminate red left-to-right
6. Release after completion
7. Press (Play) - kick is gone!

### Exercise 4: Complete Workflow Review (5 min)

**Task**: Navigate through all major functions learned this week.

Complete this sequence without looking at notes:

1. Load Project 1
2. Select Pattern 2
3. Press Play
4. Switch to Pattern 3 while playing
5. Check tempo
6. Select the Bass track
7. Switch to a different bass preset
8. Play some bass notes on keyboard
9. Transpose keyboard up one octave
10. Use pitch bend
11. Stop playback
12. Load Project 0

Time yourself - aim for under 2 minutes!

### Today's Takeaway
You can now navigate projects, manage patterns, and understand the complete structure of the OP-Z workflow.

## Week 1 Quick Reference Card

### ESSENTIAL BUTTON COMBINATIONS

**Projects**
- Load Project: [P] + Value (1-0)
- Copy Project: [P] + Source Value → [P] + Dest Value (hold)
- Clear Project: [P] + (Shift) + (Stop) (hold)
- Project Snapshot Save: [P] + (+) (hold)
- Project Snapshot Recall: [P] + (-) (hold)

**Patterns**
- Select Pattern: [P] + Step (1-16)
- Change at bar end: [P] + (Play) + Step (1-16)

**Tracks**
- Select Track: (Track) + Step (1-16)
- Select Plug: (Track) + Value Key (1-0)
- Select Preset: (Track) + Component Key (white)
- Store Preset: (Track) + Component Key (hold 2+ sec)
- Clear Track Pattern: (Track) + (Stop) (hold)

**Playback**
- Play: (Play)
- Restart: (Play) while playing
- Stop: (Stop)
- Panic: (Stop) when stopped
- Super Panic: (Stop) twice when stopped

**Tempo & Metronome**
- Check Tempo: Hold [Tempo]
- Set Tempo: [Tempo] + Value Keys (digits)
- Adjust Tempo: [Tempo] + {Green} dial
- Tap Tempo: [Tempo] + tap white keys
- Nudge Up: [Tempo] + (+)
- Nudge Down: [Tempo] + (-)
- Lock Tempo: [Tempo] + (Shift)
- Swing: [Tempo] + {Blue} dial
- Metro Volume: [Tempo] + {Red} dial
- Metro Sound: [Tempo] + {Yellow} dial

**Keyboard**
- Octave Up: (+)
- Octave Down: (-)
- Pitch Bend: Hold key + [Bend]

### LED INDICATORS

**When Holding [P]**:
- White lit = Pattern exists, is chained
- White flash = Current pattern
- Red lit = Pattern exists, not chained
- Unlit = No pattern

**When Holding (Track)**:
- White lit = Plug/preset exists
- White flash = Current selection

**During Playback**:
- Red step = Step has notes
- White step = Currently playing
- White keyboard key = Note triggering

### POLYPHONY DEFAULTS

- Drums: 2 notes
- Bass: 1 note (mono)
- Lead: 3 notes
- Arp: 1 note (arpeggiated)
- Chord: 4 notes

