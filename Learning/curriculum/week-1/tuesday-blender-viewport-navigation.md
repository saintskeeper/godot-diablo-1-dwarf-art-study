# Blender Viewport Navigation

> Week 1 | Tuesday | Blender

## Curriculum Task

**Evening (30 min):** Blender Day 1
- Open Blender, don't panic
- Learn viewport navigation (middle mouse orbit, scroll zoom, shift+middle pan)
- Select the default cube, press `G` to move, `S` to scale, `R` to rotate
- Delete cube (`X`), add a new one (`Shift+A > Mesh > Cube`)
- Save file as `week1_cube.blend`

**Resource:** Blender Guru's "Blender Beginner Tutorial Part 1" (first 15 min only)

## Written Resources

### Beginner's Guide to Blender Viewport Navigation (Vagon)
- **URL:** https://vagon.io/blog/guide-to-blender-viewport-navigation
- **Why:** Beginner-focused guide specifically for those feeling stuck or overwhelmed
- **Key takeaways:**
  - Middle mouse button + drag = rotate view (works anywhere in viewport)
  - Shift + Middle mouse = pan (slide camera sideways)
  - Scroll wheel = zoom in/out
  - These become second nature quickly

### Blender Official Manual - Navigation
- **URL:** https://docs.blender.org/manual/en/latest/editors/3dview/navigate/navigation.html
- **Why:** Authoritative reference for all navigation controls
- **Key takeaways:**
  - MMB drag to orbit around point of interest
  - Shift+MMB to pan freely
  - Ctrl+MMB for smooth zoom control
  - Use Navigation Gizmo (top-right corner) for visual reference

### Blender Fundamentals 4.5 LTS - Viewport Navigation (Blender Studio)
- **URL:** https://studio.blender.org/training/blender-fundamentals-45-lts/blender_4-5_lts_viewport-navigation/
- **Why:** Official training material, current with latest Blender
- **Key takeaways:**
  - Navigation Gizmo shows axis orientation
  - Click gizmo axes to snap to orthographic views
  - Orthographic views "flatten" the view like technical drawings

## Quick Reference

### Navigation (3-Button Mouse)
| Action | Shortcut |
|--------|----------|
| Orbit/Rotate view | Middle Mouse Button + Drag |
| Pan | Shift + MMB |
| Zoom | Scroll Wheel |
| Smooth Zoom | Ctrl + MMB |
| Frame Selected | Numpad . (period) |
| Front View | Numpad 1 |
| Side View | Numpad 3 |
| Top View | Numpad 7 |

### Object Manipulation
| Action | Shortcut |
|--------|----------|
| Select | Left Click |
| Move/Grab | G |
| Scale | S |
| Rotate | R |
| Delete | X |
| Add Object | Shift + A |
| Undo | Ctrl + Z |

### Pro Tips for Day 1
- **Don't panic** when you accidentally hit something — Ctrl+Z undoes
- After pressing G, S, or R, you can:
  - Press **X, Y, or Z** to constrain to an axis
  - Type a **number** for precise values (e.g., S + 2 = scale 2x)
  - **Right-click** to cancel the operation
- The default scene has: Camera, Cube, and Light
- Save often: **Ctrl + S**

### If You Get Lost
- Press **Numpad .** to frame your selected object
- Press **Home** to see everything in the scene
- Press **Numpad 0** to see through the camera
